# تقویم ارسال ووکامرس

افزونه انتخاب و مدیریت تاریخ ارسال سفارش برای ووکامرس با پشتیبانی از تقویم شمسی و میلادی، روزهای تعطیل و قوانین آماده‌سازی سفارش.

## ویژگی‌ها
- تقویم شمسی ایران و میلادی
- تعیین روزهای کاری و تعطیل
- تعیین روز استراحت بعد از ثبت سفارش
- پشتیبانی از سناریوی ارسال بعد از تعطیلات
- تنظیمات مخصوص پیک موتوری
- رابط فارسی و مینیمال
- سازگار با WooCommerce
