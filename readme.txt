== Description ==
Delivery Calendar adds an order delivery-date selector to WooCommerce checkout with preparation-day, weekly holiday and courier rules.

== Installation ==
1. Upload the delivery-calendar folder to /wp-content/plugins/
2. Activate the plugin.
3. Open WooCommerce > تقویم ارسال.
